Crate is a dedicated Windows desktop music manager and car synchronization engine for MP3 and FLAC collections.

- **Air-gapped & private.** Zero internet telemetry, no external network calls, completely offline.
- **Precision tagging.** Direct ID3v2.3/v2.4 and Vorbis comment parsing and writing on disk.
- **Car head unit formatting.** Auto-structures <Artist>/<Album>/<Track#> <Title>.<ext> and generates relative M3U playlists with CRLF line endings.
- **Delta synchronization.** Syncs only modified or missing files to removable USB/SD drives.
